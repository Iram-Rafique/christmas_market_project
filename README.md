# Paisley Christmas Markets

## Project Overview
Paisley Christmas Markets is a web application that allows visitors to browse traders and businesses to apply for a market stall. Administrators can manage applications by approving or rejecting them.

## Live Website
https://paisley-market-frontend.onrender.com/

## GitHub Repository
https://github.com/Iram-Rafique/christmas_market_project

## Main Features
- Browse approved traders.
- Search and view trader information.
- Submit trader applications.
- Administrator login.
- View, approve and reject applications.

## Technologies Used
- React 19 and React Router
- Tailwind CSS
- Node.js and Express.js
- MongoDB and Mongoose
- JWT and bcryptjs

## Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/Iram-Rafique/christmas_market_project.git
cd christmas_market_project
```

**2. Install frontend dependencies**
```bash
npm install
```

**3. Install backend dependencies**
```bash
cd backend
npm install
```

**4. Configure environment variables**

Create `.env` files for the frontend and backend. Add the required API URL, MongoDB connection string and authentication settings.

**5. Start the backend**
```bash
npm run dev
```

**6. Start the frontend**

From the main project directory, run:
```bash
npm start
```
